                                                                                                                                                                                                          • 集结英雄选择：由公会中战力最高、军团攻击加成最高的玩家担任集结英雄。
                                                                                                                                                                                                          • 兵种搭配：集结成员根据集结英雄的兵种偏好，或侦察报告，派出相应的克制兵种。例如，集结英雄主攻骑兵，成员可多派弓兵。
                                                                                                                                                                                                          • 连续集结与假集结：
                                                                                                                                                                                                            • 连续集结 (Chain Rallies)：在一个集结结束后，立即发动下一个集结，不给敌方喘息之机，尤其是在奇观战中，能有效压制敌方治疗速度。
                                                                                                                                                                                                            • 假集结 (Fake Rallies)：发动一个集结，但不满员，用于迷惑敌方，引诱其出兵或开启防护罩，消耗其道具。
                                                                                                                                                                                                          • debuff运用：在集结发动前，让公会成员向目标发送debuff攻击（如黑暗元素），降低敌方部队属性，提高集结成功率。 2025年，debuff的精准投放与叠加效果，是决定战局的关键。

                                                                                                                                                                                                          3. 防守策略：固若金汤，以逸待劳

                                                                                                                                                                                                          • 陷阱与城墙：升级城墙，建造并升级陷阱。在2025年，高阶陷阱能对进攻军团造成可观的伤害。
                                                                                                                                                                                                          • 藏兵与藏资源：将大部分士兵派往公会成员的城堡进行增援，或派去采集资源，只留少量士兵在城堡内，避免被敌方一锅端。将资源藏入藏宝地窖。
                                                                                                                                                                                                          • 防守英雄：在防守时，将提供防御和生命加成的英雄（如玫瑰骑士、誓言骑士）放在城墙上。
                                                                                                                                                                                                          • 反击与治疗：在敌方集结攻击后，如果己方成功防守并造成大量敌方伤兵，可考虑发动反击。同时，及时治疗己方伤兵，恢复战力。

                                                                                                                                                                                                          4. 公会协调与沟通：无缝配合，战无不胜

                                                                                                                                                                                                          • 语音沟通：在大型公会战中，使用Discord、Line等语音工具进行实时沟通，能大大提高指挥效率和反应速度。
                                                                                                                                                                                                          • 战术分工：明确公会成员的角色，例如：侦察兵、集结手、debuff手、清兵手、治疗支援等。
                                                                                                                                                                                                          • 信息共享：及时分享敌方情报、战况变化、己方伤亡情况等，让所有成员都能掌握最新动态。
                                                                                                                                                                                                          • 士气维持：公会领袖和高层应在战斗中保持积极态度，鼓励成员，提升士气。
