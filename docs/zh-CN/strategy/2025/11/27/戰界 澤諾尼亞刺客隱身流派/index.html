                                                                                                                                                                                                          优势：

                                                                                                                                                                                                          在2025年的版本中，刺客的技能平衡进行了微调，使得隐身相关技能的收益更高。以下为隐身流刺客的核心技能选择与加点建议：

                                                                                                                                                                                                          • 致命连击 (Fatal Combo)： 必满。一套快速的近战连击，对目标造成多段伤害，是爆发输出的主要来源。建议接在暗影突袭后。
                                                                                                                                                                                                          • 毒液投掷 (Poison Dart) / 烟雾弹 (Smoke Bomb)： 辅助技能，根据个人喜好和战斗环境选择。毒液投掷可提供持续伤害和减益，烟雾弹则能再次提供规避或扰乱。

                                                                                                                                                                                                          • 暗影强化 (Shadow Enhancement)： 必满。提升潜行状态下的各项属性，并缩短潜行冷却时间。 2025年版本对此技能的冷却缩减效果有所提升。
                                                                                                                                                                                                          • 暴击专精 (Critical Mastery)： 必满。进一步提升暴击率和暴击伤害，是物理输出职业的核心被动。
                                                                                                                                                                                                          • 武器专精 (Weapon Mastery)： 选择匕首专精，提升匕首类武器的伤害。

                                                                                                                                                                                                          • 敏捷 (DEX)： 核心属性，提供攻击力、暴击率、闪避率。建议主加。
                                                                                                                                                                                                          • 力量 (STR)： 提升物理攻击力。在敏捷达到一定阈值后，可适量加点以进一步提升伤害。
                                                                                                                                                                                                          • 推荐比例： 建议以3~4点敏捷搭配1点力量的比例进行加点。确保敏捷能提供足够的暴击和闪避，同时力量也能维持可观的基础伤害。

                                                                                                                                                                                                          2. 辅助属性：体力与精神的考量

                                                                                                                                                                                                          • 体力 (CON)： 提升生命值和物理防御。对于PVP玩家，适当加点体力能显著提升生存能力，避免被一套带走。 PVE则可相对减少。
                                                                                                                                                                                                          • 精神 (INT)： 提升魔法值和魔法防御。刺客对精神需求不高，通常无需加点。

                                                                                                                                                                                                          • BOSS战：
                                                                                                                                                                                                            • 开场： 潜行绕后，待BOSS技能空档或施放关键技能时，用「暗影突袭」打断或爆发输出。
                                                                                                                                                                                                            • 输出循环： 潜行 -> 暗影突袭 -> 致命连击 -> 普攻/其他技能 -> 脱战或再次潜行。
                                                                                                                                                                                                            • 规避： BOSS施放高伤害或控制技能时，立即使用潜行规避，等待时机再次切入。

                                                                                                                                                                                                          2. PVP：先手控制与爆发连招

                                                                                                                                                                                                          • 先手： 在竞技场中，利用潜行接近对手后排脆皮（法师、弓手、治疗），用「暗影突袭」打出控制并接「致命连击」瞬间爆发，力求一套秒杀。
                                                                                                                                                                                                          • 连招核心： 潜行 -> 暗影突袭 (控制) -> 致命连击 (高爆发) -> 普攻/毒液投掷 (补伤害)。
                                                                                                                                                                                                          • 走位与时机掌握：
                                                                                                                                                                                                            • 观察： 在潜行状态下观察敌方走位、技能冷却和关键目标。
                                                                                                                                                                                                            • 诱敌： 有时可故意暴露身形，引诱对手交出控制或位移技能，再利用潜行反打。
                                                                                                                                                                                                            • 脱战： 若爆发未能击杀目标，或自身血量危险，果断再次潜行脱离战斗，等待技能冷却。

                                                                                                                                                                                                            • 2025年新妖精： 关注新推出的妖精，部分可能会有专为潜行职业设计的强大增益效果。
